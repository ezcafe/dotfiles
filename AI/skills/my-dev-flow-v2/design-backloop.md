# Design-backloop (after Build)

When design is invalid after Build/Fix (contracts/IA wrong — not a code-only fix):

1. Decision N ([decisions.md](decisions.md)): Amend · Fix-only · Stop.
2. On Amend: Notes `design-backloop`; **Gate B approved: none**; **Build armed: none**; clear veto window; Next `design-update`.
3. After update → re-review until clean → Gate B again → Fix/rebuild.
4. Mark prior review/test stale ([verify.md](verify.md)).

Never silently rewrite `03`/`04` from a Build Task.
