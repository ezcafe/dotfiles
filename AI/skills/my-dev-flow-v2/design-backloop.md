# Design-backloop (after Build)

When design is invalid after Build/Fix (contracts/IA wrong — not a code-only fix):

1. Decision N ([decisions.md](decisions.md)): Amend · Fix-only · Stop.
2. On Amend: Notes `design-backloop`; **Gate B approved: none**; **Build armed: none**; clear veto window; **clear** design-scoped `gate-b auto — <HH:MM>` (or digest) token if present; set **Last Verify: pending**; **Last verify-pass at: none**; Next `design-update`. **Invalidate prior overall `03a` clean** **and** isolated `03a-api` / `03a-db` **clean** when present (set each Result **pending** or remove **clean** — prior clean is unpaid until fresh re-clean).
3. After update → re-review until clean → Gate B again → Fix/rebuild.
4. Mark prior review/test stale ([verify.md](verify.md) Stale) — keep `review-stale` / `test-stale` (do not clear them when resetting Last Verify). **skip-review carve:** `review-stale` is N/A (clear; do not Prefer review); set/keep `test-stale` until fresh `Smoke source: Smoke-Task` after a **new** **Last verify-pass at**. **lite/full:** keep until Lite/full clear ([verify.md](verify.md) Stale) — Run-log Adv+Quality / `code-review-phase` after **Last verify-pass at** for `review-stale`; `06` **Updated** (or Run-log `test-*`) after that timestamp + success + matching path for `test-stale`.

**While Notes `design-backloop`:** Prior overall `03a` **clean** **and** isolated `03a-api` / `03a-db` **clean** are **not** paid until a fresh overall + isolated re-clean after this amend ([derive-next.md](derive-next.md) Pre / Post selector · Pre-Build). Entry = **Pre-Build** Prefer unpaid `design-update`; stay on Pre-Build until Notes clear. After `design-update`, Prefer by Mode ([derive-next-pre.md](derive-next-pre.md) Expected-Next SoT): **full** → API∥DB while **Isolated unpaid** (even if files exist) → `design-review`; **simple** → `design-verify-phase`. Leftover verify-pass is unpaid (Last Verify reset + settle cleared — not **verify-pass fresh for current Gate B settlement**). Do **not** Prefer `gate-b` / `build` on stale clean. Unsafe (mirror `design-stale`): Prefer `gate-b` blocked until design re-clean; `build` blocked until Notes cleared; Post-Build / review / test / `gate-c` blocked while backloop or while verify-pass is not fresh for the current settle. Prior auto settle token is unpaid until rewritten after the fresh overall `03a` **clean**.

**Clear Notes:** Parent **MUST** remove `design-backloop` in the **same turn** as Gate B re-settle (after design re-clean) — fail-closed like Gate C consent ([hitl.md](hitl.md)); do not leave Notes set after settlement. If Notes linger: Prefer clear Notes then `build` ([derive-next-pre.md](derive-next-pre.md)). Keep `review-stale` / `test-stale` until Lite/full clear ([verify.md](verify.md) Stale) — under **skip-review**: keep `test-stale` until fresh Smoke-Task after **Last verify-pass at**; Prefer paid / Prefer `merge` \| `gate-c` only when stale Notes cleared. Example: [design-backloop-after-build.md](examples/design-backloop-after-build.md).

Never silently rewrite `03`/`04` from a Build Task.
