# Resume / abort / scope-change

## Resume

1. Read `00-run.md` Status, Last stage, card **Next**, Gate B/C / **Build armed** fields.
2. Run [derive-next.md](derive-next.md); align card or ask.
3. Async Gate B paused with veto window → treat resume as next turn: set **`Build armed: yes`** + Run log later HH:MM then Build if veto `none`.
4. Do not invent Gate B/C approved from memory.

## Abort

User reject/cancel → Status `stopped` (not `done`). Set **Build armed: none**; clear open veto window Notes as needed.

## Scope-change

API/DB/auth appears mid-run → Decision N reclassify ([decisions.md](decisions.md)); drop skip-review ([lenses.md](lenses.md)). Large pivot → new slug.
