# Artifact size caps (soft)

| Artifact | Cap |
|----------|-----|
| `02-skim.md` | ≤ ~40 lines |
| `01-idea.md` | Problem map ≤ ~25 lines (full) |
| `02-analysis.md` | Short What/Why/How; ≤5 solution pieces |
| `02b-grill.md` | ≤ ~60 lines |
| `03-design.md` | full: two options; simple: one + ≤3-line reject |
| `03a` / `04a` Fix ask | ≤10 bullets |
| `05` Fix ask | ≤15 bullets (Critical/Major only) |
| Parent Result read | First ~40 lines |

If a cap hides a Critical risk, keep the risk and cut prose.
