# Golden: Mode full + Review profile lite

**Ask:** Small feature that still needs Ideation / Gate A / two design options — not Adv→Quality→`test-full` depth.  
**Classify:** Mode **full**, profile **lite** (not full; not skip-review). HITL Gate B **blocking**.  
**Path:** Ideation → Gate A ok → skim → Analyze → Grill → Design → design-review clean → Gate B blocking → Build verify-pass (Build-writes-Smoke; skip independent Smoke) → `code-review-phase` → lenses per plan → `merge-findings` if 2+ → `test-lite` → Gate C → merge → `done`.

**Do not:** Separate `adversarial`/`quality` under lite; Mode simple + profile full; Mode full + skip-review.
