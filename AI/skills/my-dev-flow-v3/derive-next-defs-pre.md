# Derive-next Definitions — Pre (+ Both)

Open with [derive-next.md](derive-next.md) Unsafe jumps + [derive-next-pre.md](derive-next-pre.md). **Long Prefer predicates live only here** (and Post twin) — narrative files name+link.

| Term | Meaning |
|------|---------|
| **unpaid Gate A** | Mode full: `01a` missing **or** Result ≠ `ok` ([results.md](results.md)) |
| **unpaid skim** | Mode full: Gate A paid (`01a` Result `ok`) **and** (`02-skim` missing **or** Result ≠ `done`) ([results.md](results.md)) |
| **ideation unpaid** | ¬Notes `ideation-skip` **and** ¬Notes `ideation-confirmed` ([brainstorm.md](brainstorm.md)). Paid = Notes `ideation-confirmed` + provenance `ideation-confirmed` (`user:"…" ≥12 chars`) **or** Notes `ideation-skip` / preferred `ideation skipped — <reason>` (parent after Parent-relay **or** labeled solo after AskQuestion + provenance — [hitl.md](hitl.md) · [solo-entry.md](solo-entry.md)). Stages return `candidate ideation-confirmed` / `candidate ideation-skip` only ([hitl.md](hitl.md); no Prefer on waive) |
| **Analyze unpaid** | Mode full: `02-analysis` missing **or** Result ≠ `done` ([results.md](results.md)) |
| **Analyze paid** | `02-analysis` exists **and** Result **`done`** (mirror Design present — file alone / Result `pending` never pays) |
| **Design present** | `03-design.md` exists **and** Result **`done`** (paying token — Step 0 seeds **only** `00-run.md`; never treat a pre-seeded stub / Result `pending` as present — [step-0.md](step-0.md)) |
| **Design clean** / **Verify clean** | Overall `03a` **clean** **and** Isolated API/DB paid when required (`clean`\|`skipped`; Has ∈ {yes, unknown} ∧ ¬tiny / ¬Notes `tiny-contract-tweak` → file required; Mode simple: `design-verify-phase` writes those files). Notes `tiny-contract-tweak` → Isolated N/A skipped ([lenses.md](lenses.md)). **Mode simple:** Verify clean ≡ Design clean (same predicate) |
| **design-review not clean** | ¬ Design clean (incl. Isolated unpaid) |
| **backloop rewrite unpaid** | Notes `design-backloop` **and** no Run-log paying line `design-update — settle-gen:<N>` for **current** Gate B settle gen (after Notes set). Parent **or** labeled solo (acting as orchestrator) appends that line when `design-update` completes ([solo-entry.md](solo-entry.md) · [hitl.md](hitl.md)) |
| **design-stale unpaid** | Notes `design-stale` until Notes clear after Mode-full `design` + `03` rewrite — do **not** require design-update Run-log ([step-0.md](step-0.md)). Mode full only under Prefer; Mode simple ∧ Notes → Decision N ([derive-next-pre.md](derive-next-pre.md)). Under Notes (Mode full): Prefer **Grill open** → `grill` first, then unpaid **Analyze unpaid** → **Grill unpaid** → **design unpaid under design-stale** |
| **design unpaid under design-stale** | Notes `design-stale` ∧ Mode full ∧ ¬ **Grill open** → Prefer `design` rewrite **even if** `03`+Result `done` exists, until Notes clear (Mid-run Upgrade also sets `03` → `pending` — [step-0.md](step-0.md)). Never Prefer `design` while Grill open (deadlock ban); never on Mode simple |
| **design-update paid** | Run-log has `design-update — settle-gen:<N>` for current settle gen (pays **backloop rewrite**). Cleared when settle gen bumps / Notes re-set |
| **design-update unpaid** | Any `03a*` Result **`needs update`**, **or** **backloop rewrite unpaid** |
| **Isolated API/DB unpaid** | Has ∈ {yes, unknown} (not tiny / ¬Notes `tiny-contract-tweak`) and file missing **or** Result ≠ `clean` (incl. `pending`) — Prefer re-run **even if files exist**. Mode simple: Prefer `design-verify-phase` (that stage pays Isolated) — not Isolated Prefer stages |
| **Grill unpaid** | no `02b` **and** ¬Notes `grill-skip` ([grill.md](grill.md)). Missing file only — Step 0 does not seed `02b` |
| **Grill open** | ¬Notes `grill-skip` **and** (no `02b` **or** `02b` Result ≠ `frontier-empty`) — Notes `grill-skip` closes even if `02b` is `pending`/`needs-round`; Result `skipped` does **not** close (invent-waive ban); template `pending` alone does **not** close |
| **Grill closed** | ¬ **Grill open** (Notes `grill-skip` parent after Parent-relay **or** labeled solo after AskQuestion + provenance **or** Result `frontier-empty` only — [hitl.md](hitl.md) · [solo-entry.md](solo-entry.md)) |
| **design artifacts** | `02-analysis` + `03` + `04` present (ignore Grill). **Cold start** = none of {`02-analysis`, `03`, `04`} on disk — ¬(all three present) ≠ cold start (partial set = mid-run / incomplete Design) |
| **planned tests present** | `04-tasks.md` has a **Planned tests** (or equivalent cases) section with ≥1 named test case. Empty / `N/A` / missing section → **not** present (no Prefer `tdd-review`; optional Notes `04a skipped — no planned test cases` — parent **or** labeled solo) |
| **04a unpaid / dirty** | **planned tests present** **and** ¬Notes `04a skipped` **and** (`04a` missing **or** Result ∉ {`clean`}) — incl. Result `pending` \| `needs more tests`. Prefer `tdd-review` **only** when this holds. Waiver = Notes `04a skipped` (parent after Parent-relay **or** labeled solo after AskQuestion — [hitl.md](hitl.md) · [solo-entry.md](solo-entry.md); no Prefer). ¬ **planned tests present** → **not** unpaid (vacuous — no Prefer `tdd-review`) |
| **04a ok** | ¬ **04a unpaid / dirty** — i.e. ¬ planned tests present **or** Notes `04a skipped` **or** `04a` Result `clean`. Shorthand for Prefer `gate-b` / preflight Before Build / design-backloop clear (clear also needs **Gate B settled post-Notes**) |
| **Gate B settled** | Token gen == current settle gen ([gate-b.md](gate-b.md)) |
| **Gate B settled post-Notes** | Notes `design-backloop` **and** durable settle token for **current** settle gen **and** a Run-log line for that settle that appears **after** the Notes `design-backloop` line (or ISO stamp proving after — [design-backloop.md](design-backloop.md) · [gate-b.md](gate-b.md) Prefer after settle). Pre-Notes / uncleared settle does **not** count even if gen still matches — Prefer `gate-b`, not clear→`build` (incl. Mode simple auto same turn). Parent **or** labeled solo (acting as orchestrator) clears Notes `design-backloop` ([hitl.md](hitl.md) · [solo-entry.md](solo-entry.md)) |
