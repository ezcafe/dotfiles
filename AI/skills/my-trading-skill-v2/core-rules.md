# Core Rules and Guidelines

## Rule Priority

Use this order every time:

1. Hard rules (must pass)
2. Structural identity (wave family)
3. Guidelines (probability)
4. Confluence (fib/channel/indicators/psychology)

If a hard rule fails, invalidate and relabel. Do not force counts.

## Hard Rules: Standard Impulse

All three rules below must pass. If one fails, invalidate and relabel.

1. **Wave 2 boundary rule**
   - Wave 2 does not retrace beyond the start of Wave 1.

2. **Wave 3 length rule**
   - Wave 3 must satisfy both inequalities:
     - `Wave 3 >= Wave 1`
     - `Wave 3 >= Wave 5`
   - Valid length cases:
     - If Wave 1 is extended -> `Wave 3 == Wave 5`
     - If Wave 5 is extended -> `Wave 3 == Wave 1`
     - If Wave 3 is extended -> `Wave 1 == Wave 5`
     - If no wave is extended -> `Wave 1 == Wave 3` and `Wave 3 == Wave 5`

3. **Wave 4 overlap rule**
   - Wave 4 does not overlap Wave 1 price territory.

## Corrective Family Structure Gates

- ZigZag: `A-B-C` as `5-3-5`
- Flat family: `A-B-C` as `3-3-5`
- Triangle family: `A-B-C-D-E` as `3-3-3-3-3`
- Double three: `W-X-Y`
- Triple three: `W-X-Y-X-Z`

## Placement and Context Rules

- Triangles are typically continuation structures in Wave 4/B/X/Y context.
- In this framework:
  - Triangle in double three appears in `(Y)` position.
  - Triangle in triple three appears in `(Z)` position.

## Alternation Guideline

- Wave 2 and Wave 4 often differ in form:
  - one sharp/simple,
  - the other sideways/complex.

Treat alternation as a confidence booster, not invalidation by itself.

## Channeling Guideline

- Temporary channel: line through 1-3, parallel through 2.
- Wave 4 often reacts near lower rail.
- Wave 5 often targets upper rail zone.
- If Wave 4 misses expected behavior, redraw using 2-4 baseline + parallel from 3.

## Fibonacci Guideline Map

- Wave 2 retracement often around 50% / 61.8% (deeper variants possible).
- Wave 3 often extends 161.8% or beyond relative to Wave 1.
- Wave 4 often shallower than Wave 2.
- Wave 5 projection is variable; branch scenarios instead of single-point certainty.
- Corrective C vs A common relationships: 0.618, 1.0, 1.618.

## Validation Discipline

- Structure first, measurement second.
- Fib miss alone does not invalidate a count.
- Rule break invalidates a count immediately.
