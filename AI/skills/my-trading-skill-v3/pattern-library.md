# Pattern Library

## Motive Patterns

### Impulse (1-2-3-4-5)

| Property | Value |
|---|---|
| Structure | Five waves in trend direction; Waves 1, 3, 5 motive; Waves 2, 4 corrective |
| Hard rules | Wave 2 not beyond Wave 1 start; Wave 3 not shortest; Wave 4 no overlap into Wave 1 |
| Common position | Primary trend legs at any degree |
| Quick test | (1) Five distinct swings, (2) three hard rules pass, (3) motive legs show internal subdivisions |

### Leading Diagonal

| Property | Value |
|---|---|
| Structure | Five waves with wedge geometry; Wave 4 overlaps Wave 1 |
| Internal | Commonly 3-3-3-3-3 or 5-3-5-3-5 |
| Common position | Wave 1 of impulse or Wave A of correction |
| Quick test | (1) Wave 4 overlaps Wave 1, (2) contracting/parallel trendlines, (3) Wave 3 not shortest |

### Ending Diagonal

| Property | Value |
|---|---|
| Structure | Five waves with contracting wedge; Wave 4 overlaps Wave 1; commonly 3-3-3-3-3 |
| Completion | Momentum divergence into Wave 5; possible brief wedge overshoot then reversal |
| Common position | Wave 5 of impulse or Wave C of correction (terminal) |
| Quick test | (1) Terminal position, (2) wedge geometry with overlap, (3) Wave 4 not beyond Wave 2 start |

### Truncation (Fifth-Wave Failure)

| Property | Value |
|---|---|
| Structure | Wave 5 fails to exceed Wave 3 extreme |
| Likelihood | Higher after a strong extended Wave 3 |
| Classical analog | Double top / double bottom |
| Quick test | (1) Confirm internal five-wave subdivision in the truncated Wave 5, (2) verify Wave 3 was extended |

### Extensions

| Property | Value |
|---|---|
| Identification | One motive leg shows amplified internal subdivisions relative to others |
| Most common | Wave 3 extension |
| Branch logic | If Wave 3 near Wave 1 size, bias toward Wave 5 extension; if Wave 3 clearly extended, Wave 5 often comparable to Wave 1 |
| Nested behavior | An extension can contain its own internal extension (fifth of fifth) |

## Corrective Patterns -- Zigzag Family

### Single Zigzag (A-B-C, 5-3-5)

| Property | Value |
|---|---|
| Structure | A motive/diagonal, B corrective only, C impulse/ending diagonal |
| Shape | Usually sharp; often fits descending wedge / parallel channel appearance |
| B constraint | B shorter than A; top of B noticeably lower than start of A (bearish framing) |
| C target | Commonly 100% to 161.8% of A |
| Common position | Wave 2; also connective component inside complex corrections |
| Quick test | (1) Three legs with 5-3-5 internal, (2) B shorter than A, (3) sharp character |

### Double Zigzag (W-X-Y as zigzag-X-zigzag)

| Property | Value |
|---|---|
| Structure | Two zigzags separated by a corrective X wave |
| Purpose | When first zigzag does not correct far enough |
| C vs A | Apply 0.618/1.0/1.618 multiples separately to each zigzag leg |
| Character | Steeper than a double three; more price correction than time correction |

## Corrective Patterns -- Flat Family (A-B-C, 3-3-5)

### Regular Flat

| Property | Value |
|---|---|
| Structure | A corrective (3), B corrective (3), C motive (5) |
| B boundary | B stays within or near A's starting level |
| C boundary | C does not go much beyond A's extreme |
| Character | Sideways, choppy; traps intraday traders with fake breakouts |
| Quick test | (1) A=3, B=3, C=5, (2) B near A-start, (3) C near A-extreme |

### Expanded Flat

| Property | Value |
|---|---|
| Structure | 3-3-5 with extended B and extended C |
| B boundary | B ends beyond the start of A (fake breakout above last high) |
| C boundary | C extends beyond A's extreme in counter-trend direction |
| Quick test | (1) A=3, B=3, C=5, (2) B beyond A-start, (3) C beyond A-extreme |

### Running Flat

| Property | Value |
|---|---|
| Structure | 3-3-5; least common flat variant |
| B boundary | B ends beyond the start of A |
| C boundary | C fails to reach A's extreme against the dominant trend (C stays "running" with trend) |
| Context | Very strong, fast markets; confirmation often comes late near end of Wave C |
| C length | Often approximately same length as A |
| Quick test | (1) A=3, B=3, C=5, (2) B beyond A-start, (3) C does NOT reach A-extreme against trend |

### Flat Family Disambiguation

| Variant | B vs A-start | C vs A-extreme |
|---|---|---|
| Regular | Within/near | Near (not much beyond) |
| Expanded | Beyond | Beyond (deeper against trend) |
| Running | Beyond | Short of (fails to reach, stays with trend) |

## Corrective Patterns -- Triangle Family (A-B-C-D-E, 3-3-3-3-3)

### Shared Triangle Properties

- Five overlapping corrective waves (A through E), each internally three-wave.
- Position: Wave 4, B, X, or Y only. Never Wave 2 or A.
- Continuation pattern: completed triangle continues the prior dominant trend.
- Post-triangle thrust often travels about the width of the widest part of the triangle.
- Wave E can overshoot the trendline; E can itself be a triangle.

### Contracting Triangle (Symmetrical)

| Property | Value |
|---|---|
| Geometry | Upper trendline slopes down, lower trendline slopes up (converging) |
| Most common | Most frequently seen triangle form |
| Quick test | (1) Five legs A-E, (2) all legs corrective (3-3-3-3-3), (3) converging boundaries |

### Barrier Triangle

| Property | Value |
|---|---|
| Geometry | One boundary horizontal (B-D line or A-C-E line); other boundary angled |
| Key distinction | Waves B and D end at essentially the same level (flat barrier at one side) |
| Classical analog | Ascending triangle (horizontal resistance, rising support/higher lows) |
| Quick test | (1) Five legs A-E, (2) one rail flat / one angled, (3) B approximately equals D level |

### Expanded Triangle

| Property | Value |
|---|---|
| Geometry | Diverging boundaries; B-D line diverges from A-C line |
| Key distinction | C beyond A, D beyond B, E beyond C (same-direction progression; wider swings) |
| Character | Volatility expands inside the pattern |
| Quick test | (1) Five legs A-E, (2) diverging rails, (3) each wave extends past prior same-direction pivot |

### Triangle Disambiguation

| Variant | Boundaries | B vs D | C/D/E behavior |
|---|---|---|---|
| Contracting | Converging | Different levels | Swings compress |
| Barrier | One flat, one angled | Same level (flat rail) | Compression on angled side |
| Expanded | Diverging | D beyond B | C, D, E each extend past prior same-direction wave |

## Combination Patterns

### Double Three (W-X-Y)

| Property | Value |
|---|---|
| Structure | Two simple corrective structures connected by X |
| W | First corrective leg: flat, expanded flat, or zigzag (A-B-C) |
| X | Connector: usually zigzag, can be any corrective form |
| Y | Second corrective leg: flat, zigzag, or triangle (a-b-c-d-e) |
| Character | Sideways/horizontal consolidation (not steep like double zigzag) |
| Constraints | Triangle only in (Y); zigzag at most once in the combination |
| Alternation | Legs tend to alternate form (flat then triangle more common than flat then flat) |
| Purpose | Extends correction duration (time), not necessarily depth |
| Common position | Often in Wave 4 (shallower part) |

### Triple Three (W-X-Y-X-Z)

| Property | Value |
|---|---|
| Structure | Three simple corrective structures connected by two X waves |
| W | First corrective leg: flat or zigzag |
| X (first) | Connector: usually zigzag |
| Y | Second corrective leg: flat or zigzag (not triangle) |
| X (second) | Connector: usually zigzag |
| Z | Third and final leg: flat, zigzag, or triangle (marks end of correction) |
| Constraints | Triangle only in (Z); both X waves often zig-zags but can be any form |
| Character | Prolonged sideways range; full of false breakouts and messy price action |
| Trading note | Most traders lose in these; often best to wait for clear exit signal |

### Combination Disambiguation

| Pattern | Segments | Triangle allowed in | Zigzag max count | Character |
|---|---|---|---|---|
| Double three (W-X-Y) | 2 legs + 1 X | Y only | 1 | Sideways |
| Triple three (W-X-Y-X-Z) | 3 legs + 2 X | Z only | Per-leg | Extended sideways |
| Double zigzag | 2 zigzags + 1 X | N/A | 2 | Steep correction |

## Classical Chart Patterns (Secondary Confluence)

These are subordinate to Elliott structure. Use only as confluence, not as replacements for wave rules.

### Continuation Patterns

| Pattern | Shape | Entry Zone | Elliott Alignment |
|---|---|---|---|
| Symmetrical triangle | Converging boundaries, swing compression | Breakout in prior-trend direction | Wave 4, B, or post-correction continuation |
| Ascending triangle | Flat upper boundary, rising lower boundary | Resistance breakout | Barrier triangle shape; Wave 4/B continuation |
| Bull flag | Downward-sloping channel after impulse | Upper-bound break | Post-Wave-3 pause or Wave 4 resolution |

### Reversal Patterns

| Pattern | Shape | Entry Zone | Elliott Alignment |
|---|---|---|---|
| Inverse head & shoulders | Left shoulder, head, right shoulder | Neckline break/reclaim | Wave C completion / terminal exhaustion |
| Double bottom | Two comparable lows at support | Neckline breakout | Truncation or Wave C terminus |
| Falling wedge | Contracting downward wedge | Upper-bound break | Ending diagonal completion |
| Cup and handle | Rounded base + smaller pullback | Resistance breakout from handle | Post-correction Wave 1 or Wave 3 initiation |

### Integration Rules

- If chart pattern and Elliott structure disagree, prioritize wave-rule validity.
- Strongest confluence: continuation patterns with Wave 3/5 extension or post-Wave-4; reversal patterns with C-wave/terminal exhaustion.
- Always provide one invalidation condition from structure (boundary break or failed reclaim).
