# Fibonacci Map

All levels are probability zones, not single-price certainties. Structure must be valid before applying fibonacci targets. A fib miss alone does not invalidate a count; a rule break does.

## Motive Wave Multiples

Measure each wave relative to its basis wave. Apply in sequence as the count develops.

| Wave | Basis | Target Zones | Branch Condition |
|---|---|---|---|
| Wave 1 | N/A | No predetermined target (origin wave) | -- |
| Wave 2 | Retracement of Wave 1 | 50%, 61.8% (deeper: 76.4%, 85.4%) | Must not retrace beyond 100% of Wave 1 |
| Wave 3 | Extension of Wave 1 from Wave 2 pivot | 161.8%, 261.8% (rare: beyond 261.8%) | Must not be shortest among 1, 3, 5 |
| Wave 4 | Retracement of Wave 3 | 23.6%, 38.2% | Must not overlap Wave 1 territory |
| Wave 5 (W3 extended) | Relative to Wave 1 | 100%, 161.8%, 261.8% of Wave 1 | Wave 5 often comparable to Wave 1 |
| Wave 5 (W3 not extended) | Relative to Wave 1-to-3 move | 161.8% of start-of-1 to top-of-3 | Wave 5 may extend; keep two scenarios active |
| Wave 5 (from W4) | Extension from Wave 4 | 61.8%, 100%, 123.6% | Alternative measurement anchor |

### Decision Flow

1. Confirm structural position before projecting.
2. Compute Wave 2 retracement of Wave 1.
3. From Wave 2 pivot, project Wave 3 as 1.618 / 2.618 x Wave 1.
4. After Wave 3 confirms, project Wave 4 at 0.236 / 0.382 of Wave 3.
5. For Wave 5, branch by whether Wave 3 appears extended; map both outcomes.
6. Mark all projections as zones; combine with channeling, alternation, and subdivisions.

## Corrective C vs A Multiples

Wave C commonly relates to Wave A by these length multiples. Measure A as one full leg, then compare C's traveled distance.

| Pattern | C-to-A Ratio Zones | Measurement Notes |
|---|---|---|
| Zigzag (5-3-5) | 0.618, **1.0** (default), 1.618 | C often equals A; 1.0 is the most common |
| Double zigzag -- each leg | 0.618, 1.0, 1.618 | Apply separately to (W) and (Y) zig-zag legs |
| Regular / sideways flat | A, B, C often similar extent | Structural 3-3-5 rules apply |
| Extended flat | **1.618** x A | Measured from start of B to end of C |

## Post-Impulse ABC Identification

After a completed five-wave impulse (4-5 segment), use this method to locate the corrective A-B-C that follows. Bearish correction after a bull 1-5 shown; mirror anchors for bullish ABC after a bear impulse.

| Step | Wave | Fib Tool | Anchor Points | Target Zones |
|---|---|---|---|---|
| 1 | Wave A | Retracement | Wave 4 -> Wave 5 (last impulse swing) | 38.2%, 50% of 4-5 segment |
| 2 | Wave B | Retracement | Wave 5 -> end of Wave A | 38.2%, 50% of 5-A segment |
| 3 | Wave C | Extension | A-leg projection | 138.2%, 161.8% extension from A |

After estimating C, cross-check with C-vs-A multiples (0.618 / 1.0 / 1.618) as confluent zones.

### Sequence Discipline

- Estimate A first from the 4-5 retracement.
- Estimate B only after A pivot is reasonably confirmed.
- Estimate C only after both A and B pivots are in place.
- Validate with C-vs-A multiples as a second measurement layer.

## Fibonacci Retracement Quick Reference

### Common Levels

| Level | Usage |
|---|---|
| 23.6% | Shallow reaction; fast confirmation needed |
| 38.2% | Common reaction zone; frequent in Wave 4 |
| 50% | Psychological midpoint (not a Fibonacci-sequence ratio); widely watched |
| 61.8% | Most common retracement reaction zone; frequent in Wave 2 |
| 76.4% | Deeper pullback zone |
| 78.6%, 85.4%, 88.6% | Deep retracement zones before continuation attempt |

### Anchoring Rules

| Trend Context | Anchor Direction | Levels Read As |
|---|---|---|
| Bullish | Swing low -> swing high | Potential support during pullback |
| Bearish | Swing high -> swing low | Potential resistance during rebound |

### Confirmation Workflow

1. Identify trend direction and anchor to the prior continuous swing.
2. Mark levels as zone bands, not single-price triggers.
3. Wait for local confirmation (structure, momentum, or indicator alignment).
4. Expect failed reversals, especially around 38.2% and 50%.
5. Keep an alternate scenario active when a level fails to hold.

## Validation Discipline

- Structure first, measurement second.
- Fib miss alone does not invalidate a count.
- Rule break (Wave 2 beyond 100% of Wave 1; Wave 3 shortest; Wave 4 into Wave 1 territory) invalidates the count immediately.
- If Wave 3 exceeds standard extension zones materially, keep alternate Wave 5 scenarios active rather than forcing a single endpoint.
