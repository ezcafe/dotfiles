# Core Rules

## Rule Priority

1. Hard rules (must pass -- if any fails, invalidate and relabel)
2. Structural identity (wave family classification)
3. Guidelines (probability -- failure alone does not invalidate)
4. Confluence (fib, channel, indicators, psychology)

## Impulse Hard Rules

All three must pass for a valid standard impulse (1-2-3-4-5).

| # | Rule | Condition | On Failure |
|---|---|---|---|
| 1 | Wave 2 boundary | Wave 2 does not retrace beyond the start of Wave 1 | Invalidate impulse label |
| 2 | Wave 3 length | Wave 3 is never the shortest among Waves 1, 3, and 5 | Invalidate impulse label |
| 3 | Wave 4 overlap | Wave 4 does not enter Wave 1 price territory | Relabel as diagonal or other structure |

Wave 3 length detail -- valid cases when one wave is extended:

- Wave 1 extended: Wave 3 >= Wave 5
- Wave 3 extended: Wave 1 approximately equals Wave 5
- Wave 5 extended: Wave 3 >= Wave 1
- No extension: Wave 1, 3, 5 roughly comparable; Wave 3 still not shortest

## Corrective Family Gates

| Family | Label | Internal Structure | Key Constraint |
|---|---|---|---|
| Zigzag | A-B-C | 5-3-5 | A motive or diagonal; B corrective only; C impulse or ending diagonal |
| Flat | A-B-C | 3-3-5 | A and B both corrective; C motive |
| Triangle | A-B-C-D-E | 3-3-3-3-3 | Five overlapping corrective legs; position restricted to 4/B/X/Y |
| Double three | W-X-Y | Two correctives + connector | Triangle only in (Y); zigzag at most once |
| Triple three | W-X-Y-X-Z | Three correctives + two connectors | Triangle only in (Z); X waves usually zigzag |

## Leading Diagonal Rules

A motive wave that is not a standard impulse. Appears as Wave 1 of an impulse or Wave A of a correction.

| Property | Rule |
|---|---|
| Geometry | Wedge-like with contracting or parallel trendlines |
| Overlap | Wave 4 overlaps Wave 1 territory (allowed; this would invalidate a standard impulse) |
| Wave 3 | Still must not be the shortest among 1, 3, 5 |
| Internal structure | Commonly 3-3-3-3-3 or 5-3-5-3-5 |
| Retracement | Wave 4 retracement usually smaller than Wave 2 |
| Follow-through | Typically followed by Wave 2 (if in impulse) or Wave B (if diagonal is Wave A) |

## Ending Diagonal Rules

A terminal motive structure. Appears as Wave 5 of an impulse or Wave C of an ABC correction.

| Property | Rule |
|---|---|
| Geometry | Wedge-like with contracting trendlines and overlapping internals |
| Overlap | Wave 4 overlaps Wave 1 territory |
| Wave 4 vs Wave 2 | Wave 4 must not move beyond the start of Wave 2 |
| Wave 3 | Must not be shortest among 1, 3, 5 |
| Internal structure | Commonly 3-3-3-3-3 (corrective legs, often zigzag-style) |
| Wave 1 | Often the longest; Wave 5 frequently weaker than Wave 3 |
| Completion signals | Momentum divergence (RSI/MACD) into Wave 5; possible brief overshoot of wedge boundary |
| Post-completion | Elevated reversal risk; retracement toward diagonal origin is common |

## Truncation (Fifth-Wave Failure)

| Property | Rule |
|---|---|
| Definition | Wave 5 fails to exceed the end of Wave 3 |
| Likelihood | More common after a strong extended Wave 3 |
| Validation | Confirm internal five-wave subdivision before assigning truncation label |
| Classical analog | Resembles double top / double bottom setup |

## Extension Rules

| Condition | Implication |
|---|---|
| Most impulses contain one extension | Commonly Wave 3; also Wave 1 or Wave 5 |
| Extension identification | One motive leg shows amplified internal subdivisions relative to others |
| Wave 3 near Wave 1 size | Bias toward possible Wave 5 extension |
| Wave 3 clearly extended | Wave 5 often behaves closer to Wave 1 in length/time |
| Nested extension | An extension can contain an internal extension (e.g. fifth of fifth) |
| Nested trap | Apparent five-wave completion may continue printing new extremes |
| Mixed evidence | Maintain branch scenarios rather than forcing single endpoint |

## Degree Hierarchy

Common tiers (highest to lowest):

Grand Supercycle > Supercycle > Cycle > Primary > Intermediate > Minor > Minute > Minuette > Subminuette

Nesting logic:

- A completed five-wave sequence on a lower timeframe completes one wave of a higher degree (typically higher-degree 1, 3, or 5).
- A completed a-b-c on a lower timeframe completes the higher degree's corrective wave (typically higher-degree 2 or 4).
- Practical focus: Primary, Intermediate, and Minor for day-to-day counting.
- Preferred reading order: 1D / 4H / 1H for higher-degree context first, then lower timeframes for refinement.
- If degree is ambiguous, keep alternate counts one degree higher/lower rather than forcing precision.

## Quick Differentiation: Impulse vs Diagonal

1. If Wave 4 overlaps Wave 1 territory --> favor diagonal (impulse is invalid under overlap rule).
2. If Wave 4 does NOT overlap Wave 1 --> impulse is the default (still validate Wave 2 boundary and Wave 3 length).
3. Wedge-like geometry with expected overlap/retracement behavior --> further supports diagonal.
4. Terminal position (Wave 5 or Wave C) --> ending diagonal. Origin position (Wave 1 or Wave A) --> leading diagonal.
